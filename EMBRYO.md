# Embryo Object Store

Embryo Object Store is Embryo-Zero's fork of [minio](https://github.com/minio/minio) (7aac2a2, commit 7aac2a2). It does S3-compatible object storage.

- Our changes live on the `embryo` branch. The original license files (LICENSE, NOTICE) are unchanged.
- Legal notes: LEGAL.md. Dated list of our changes: CHANGES-EMBRYO.md.
